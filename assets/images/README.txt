E-PERPUS — INDIVIDUAL HD ASSET PACK
===================================

Setiap gambar di folder ini adalah asset INDIVIDUAL, bukan sprite sheet atau moodboard.

STRUKTUR
--------
backgrounds/   : background halaman, masing-masing 1920x1080
illustrations/ : ilustrasi terpisah, PNG RGBA/transparan
                resolusi tinggi (umumnya 1024–1536 px sisi utama)
decorations/   : dekorasi transparan terpisah, 1024x1024

CATATAN
-------
- Ilustrasi dan dekorasi menggunakan PNG dengan alpha/transparansi.
- Background memang full-frame dan tidak transparan.
- File di folder illustrations tidak berisi layout halaman web/sheet asset.
- Asset dapat langsung dipakai di HTML/CSS sebagai <img> atau background-image.
